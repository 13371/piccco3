# 配置邮件服务说明

## 📧 问题说明

当前后端服务器缺少 SMTP 邮件服务配置，导致无法发送验证码邮件。错误信息：
- "邮件服务未配置，请联系管理员"
- API `/api/auth/send-code` 返回 500 错误

## ✅ 解决方案

需要在 `backend/.env` 文件中配置 SMTP 邮件服务。

---

## 🔧 配置步骤

### 1. 编辑 `.env` 文件

打开 `D:\piccco3-new\backend\.env` 文件，配置以下变量：

```env
SMTP_HOST=smtp.xxx.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@example.com
SMTP_PASS=your-password-or-app-password
```

### 2. 不同邮箱服务商的配置

#### Gmail（推荐用于开发测试）

1. **启用两步验证**：
   - 登录 Google 账号
   - 进入"安全性" → "两步验证" → 启用

2. **生成应用专用密码**：
   - 进入"安全性" → "应用专用密码"
   - 生成新密码（16位字符）
   - 使用这个密码作为 `SMTP_PASS`

3. **配置**：
```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-16-char-app-password
```

#### QQ 邮箱

1. **开启 SMTP 服务**：
   - 登录 QQ 邮箱
   - 设置 → 账户 → 开启"POP3/SMTP服务"
   - 获取授权码（16位字符）

2. **配置**：
```env
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@qq.com
SMTP_PASS=your-authorization-code
```

#### 163 邮箱

1. **开启 SMTP 服务**：
   - 登录 163 邮箱
   - 设置 → POP3/SMTP/IMAP
   - 开启"SMTP服务"
   - 获取授权码

2. **配置**：
```env
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@163.com
SMTP_PASS=your-authorization-code
```

#### Outlook/Hotmail

```env
SMTP_HOST=smtp-mail.outlook.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-email@outlook.com
SMTP_PASS=your-password
```

## 🔄 重启后端服务器

配置完成后，需要重启后端服务器使配置生效：

```powershell
# 1. 停止当前后端服务器
Get-Process | Where-Object {$_.ProcessName -eq "node" -and (Get-NetTCPConnection -OwningProcess $_.Id -ErrorAction SilentlyContinue | Where-Object {$_.LocalPort -eq 4000})} | Stop-Process

# 2. 重新启动后端服务器
cd D:\piccco3-new\backend
npm start
```

或者手动：
1. 在任务管理器中找到运行在端口 4000 的 Node.js 进程并结束
2. 重新运行 `npm start`

## 🚨 常见问题

### 1. "SMTP 未配置" 错误

**原因**：`.env` 文件中的 SMTP 配置为空或未正确设置

**解决**：
- 检查 `.env` 文件是否存在
- 确认 `SMTP_HOST`、`SMTP_USER`、`SMTP_PASS` 都已填写
- 重启后端服务器

### 2. "认证失败" 错误

**原因**：邮箱密码或授权码错误

**解决**：
- Gmail：使用应用专用密码，不是普通密码
- QQ/163：使用授权码，不是邮箱登录密码
- 确认密码中没有多余的空格

### 3. "连接超时" 错误

**原因**：SMTP 服务器地址或端口配置错误

**解决**：
- 检查 `SMTP_HOST` 是否正确
- 检查 `SMTP_PORT` 是否正确
- 检查防火墙是否阻止连接

### 4. 开发环境测试（可选）

如果暂时无法配置真实邮箱，可以：

1. **使用测试邮箱服务**（如 Mailtrap、Ethereal Email）
2. **临时禁用邮件验证**（仅用于开发，不推荐）
3. **使用控制台输出验证码**（修改代码，将验证码输出到控制台）

## 📝 配置示例

完整的 `.env` 文件示例（Gmail）：

```env
PORT=4000
NODE_ENV=development
FRONTEND_ORIGIN=http://localhost:5173

JWT_SECRET=dev-secret-change-me-in-production
SESSION_SECRET=dev-session-secret-change-me-in-production

SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@gmail.com
SMTP_PASS=abcd efgh ijkl mnop
```

## 🔒 安全提示

1. **不要将 `.env` 文件提交到 Git**
2. **生产环境使用强密码和安全的 JWT_SECRET**
3. **定期更换邮箱授权码**
4. **使用环境变量管理敏感信息**
