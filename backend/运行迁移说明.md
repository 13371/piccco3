# 数据库迁移说明

## 迁移内容

本次迁移包含两个部分：

1. **迁移 005**: 在 `folders` 表中添加 `password` 字段（用于隐私文件夹密码）
2. **迁移 006**: 在 `user_settings` 表中添加 `home_content` 字段（用于首页内容）

## 快速执行迁移

### 方法1：使用 Node.js 脚本（推荐）

```bash
# 1. 进入后端目录
cd backend

# 2. 确保已安装依赖
npm install

# 3. 执行迁移脚本
node scripts/run-migration-005-006.js
```

### 方法2：使用 npm 脚本（如果已添加到 package.json）

```bash
cd backend
npm run migrate:005-006
```

## 迁移前检查

1. **确认数据库配置**
   - 检查 `.env` 文件中的数据库配置：
     ```
     DB_HOST=your-db-host
     DB_PORT=5432
     DB_NAME=piccco
     DB_USER=your-db-user
     DB_PASSWORD=your-db-password
     ```

2. **确认数据库连接**
   - 确保数据库服务正在运行
   - 确保数据库用户有 `ALTER TABLE` 权限

3. **备份数据库**（推荐）
   ```bash
   # 备份数据库（使用 pg_dump）
   pg_dump -h your-db-host -U your-db-user -d piccco > backup_$(date +%Y%m%d_%H%M%S).sql
   ```

## 迁移脚本说明

迁移脚本 `scripts/run-migration-005-006.js` 会：

1. 自动读取 `.env` 文件中的数据库配置
2. 检查字段是否已存在（避免重复添加）
3. 添加缺失的字段
4. 添加字段注释
5. 验证迁移结果

## 迁移后验证

迁移完成后，可以验证字段是否已添加：

```sql
-- 检查 folders 表的 password 字段
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'folders' AND column_name = 'password';

-- 检查 user_settings 表的 home_content 字段
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'user_settings' AND column_name = 'home_content';
```

## 故障排除

### 错误：连接数据库失败

**原因**：数据库配置不正确或数据库服务未运行

**解决方法**：
1. 检查 `.env` 文件中的数据库配置
2. 确认数据库服务正在运行
3. 测试数据库连接：
   ```bash
   psql -h your-db-host -U your-db-user -d piccco
   ```

### 错误：权限不足

**原因**：数据库用户没有 `ALTER TABLE` 权限

**解决方法**：
1. 使用具有管理员权限的用户（如 `postgres`）
2. 或者授予当前用户权限：
   ```sql
   GRANT ALTER ON ALL TABLES IN SCHEMA public TO your-db-user;
   ```

### 错误：字段已存在

**说明**：这是正常的，脚本会自动检测并跳过已存在的字段。

## 手动执行 SQL（如果脚本失败）

如果脚本执行失败，可以手动执行以下 SQL：

```sql
-- 迁移 005: 添加文件夹密码字段
ALTER TABLE folders 
ADD COLUMN IF NOT EXISTS password TEXT;

COMMENT ON COLUMN folders.password IS '隐私文件夹密码（加密存储）';

-- 迁移 006: 添加首页内容字段
ALTER TABLE user_settings 
ADD COLUMN IF NOT EXISTS home_content TEXT DEFAULT '';

COMMENT ON COLUMN user_settings.home_content IS '首页大白框内容';
```

## 注意事项

1. ⚠️ **迁移前请备份数据库**
2. ⚠️ **迁移期间不要重启后端服务**
3. ⚠️ **迁移完成后需要重启后端服务以应用更改**
4. ✅ 迁移脚本是幂等的，可以安全地多次运行

## 迁移完成后

迁移完成后，需要：

1. **重启后端服务**
   ```bash
   pm2 restart piccco-backend
   # 或
   npm start
   ```

2. **验证功能**
   - 测试首页内容同步
   - 测试隐私文件夹密码同步

## 回滚（如果需要）

如果需要回滚迁移，可以执行：

```sql
-- 删除 home_content 字段
ALTER TABLE user_settings DROP COLUMN IF EXISTS home_content;

-- 删除 password 字段
ALTER TABLE folders DROP COLUMN IF EXISTS password;
```

**注意**：回滚会丢失数据，请谨慎操作！
