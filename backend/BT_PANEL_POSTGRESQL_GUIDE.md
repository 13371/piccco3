# 宝塔面板 PostgreSQL 安装和配置指南

## 📋 概述

如果您使用宝塔面板管理服务器，需要先在宝塔面板中安装 PostgreSQL，然后再进行数据库迁移。

---

## 第一步：在宝塔面板安装 PostgreSQL

### 1.1 打开 PostgreSQL 管理器

1. 登录宝塔面板
2. 在左侧菜单找到 **"数据库"** 或 **"软件商店"**
3. 搜索 **"PostgreSQL"** 或 **"PostgreSQL管理器"**
4. 点击 **"PostgreSQL管理器"** 插件

### 1.2 安装 PostgreSQL 管理器

1. 点击 **"立即安装"** 按钮
2. 选择版本（推荐选择 **"2.8 Stable"** 或最新稳定版）
3. 等待安装完成（可能需要几分钟）

### 1.3 重要提示

⚠️ **安装前请注意**：
- 如果已存在此插件，文件将被替换
- **请手动安装插件扩展和依赖环境**，如果未安装，将无法正常使用
- 安装过程可能需要几分钟时间，请耐心等候

---

## 第二步：安装 PostgreSQL 数据库

### 2.1 打开 PostgreSQL 管理器

安装完成后，在宝塔面板左侧菜单找到 **"数据库"** → **"PostgreSQL管理器"**

### 2.2 安装 PostgreSQL 数据库

1. 点击 **"版本管理"** 菜单
2. 选择要安装的 PostgreSQL 版本（推荐 **14.x** 或 **15.x**）
3. 点击 **"安装"** 按钮
4. 等待安装完成

### 2.3 启动 PostgreSQL 服务

1. 点击 **"服务状态"** 菜单
2. 确保状态显示为 **"开启"**（绿色）
3. 如果未开启，点击 **"启动"** 按钮

---

## 第三步：创建数据库和用户

### 3.1 创建数据库

1. 在 PostgreSQL 管理器中，点击 **"数据库列表"** 菜单
2. 点击 **"添加数据库"** 按钮
3. 填写信息：
   - **数据库名**：`piccco`
   - **用户名**：`piccco_user`
   - **密码**：设置一个强密码（请记住这个密码！）
   - **备注**：`piccco应用数据库`（可选）
4. 点击 **"提交"** 或 **"确定"**

### 3.2 验证数据库创建

在数据库列表中，应该能看到新创建的 `piccco` 数据库。

---

## 第四步：获取数据库连接信息

### 4.1 查看端口信息

1. 在 PostgreSQL 管理器中，点击 **"端口"** 菜单
2. 记录 PostgreSQL 的端口号（默认是 **5432**）

### 4.2 查看存储位置（可选）

1. 点击 **"存储位置"** 菜单
2. 可以查看数据库文件的存储路径

---

## 第五步：配置应用环境变量

### 5.1 编辑 .env 文件

在服务器上编辑 `backend/.env` 文件：

```bash
# 使用宝塔面板的文件管理器
# 或使用 SSH 连接服务器
cd /www/wwwroot/your-project/backend
nano .env
```

### 5.2 添加数据库配置

在 `.env` 文件中添加：

```env
# ============================================
# 数据库配置（宝塔面板）
# ============================================
DB_HOST=localhost
DB_PORT=5432  # 如果宝塔面板中显示的是其他端口，请修改
DB_NAME=piccco
DB_USER=piccco_user
DB_PASSWORD=your_password  # 替换为第三步设置的密码

# 存储模式配置
# 'file' - 仅使用文件存储（默认，当前模式）
# 'db' - 仅使用数据库存储
# 'dual' - 双写模式（同时写入文件和数据库，推荐过渡期使用）
STORAGE_MODE=file

# 数据库连接池配置（可选）
DB_POOL_MAX=20
DB_IDLE_TIMEOUT=30000
DB_CONNECTION_TIMEOUT=2000
```

### 5.3 保存文件

保存 `.env` 文件。

---

## 第六步：安装 Node.js 依赖

### 6.1 使用宝塔面板终端

1. 在宝塔面板中，点击 **"终端"** 菜单
2. 或使用 SSH 连接到服务器

### 6.2 安装依赖

```bash
# 进入项目目录
cd /www/wwwroot/your-project/backend

# 安装依赖
npm install
```

### 6.3 验证安装

```bash
# 检查 pg 包是否安装成功
npm list pg
```

---

## 第七步：创建数据库 Schema

### 7.1 使用宝塔面板终端

在宝塔面板终端中执行：

```bash
# 进入项目目录
cd /www/wwwroot/your-project/backend

# 执行 SQL 文件
psql -U piccco_user -d piccco -h localhost -f migrations/001_create_schema.sql
```

**如果提示输入密码**，输入第三步设置的数据库密码。

### 7.2 或者使用宝塔面板的数据库管理工具

1. 在 PostgreSQL 管理器中，点击 **"数据库列表"**
2. 找到 `piccco` 数据库，点击 **"管理"** 或 **"phpPgAdmin"**
3. 在 SQL 查询窗口中，复制 `migrations/001_create_schema.sql` 文件的内容
4. 粘贴并执行

## 常见问题

### Q1: 宝塔面板找不到 PostgreSQL 管理器

**解决**：
1. 在 **"软件商店"** 中搜索 "PostgreSQL"
2. 确保已安装 **"PostgreSQL管理器"** 插件
3. 如果找不到，可能需要更新宝塔面板

### Q2: PostgreSQL 服务无法启动

**检查**：
1. 查看 **"服务状态"** 中的错误信息
2. 检查端口是否被占用
3. 查看 **"日志"** 菜单中的错误日志

### Q3: 无法连接数据库

**检查**：
1. PostgreSQL 服务是否运行
2. 端口号是否正确
3. 用户名和密码是否正确
4. `.env` 文件配置是否正确

### Q4: 执行 SQL 文件失败

**解决**：
1. 使用宝塔面板的数据库管理工具执行
2. 或使用 `psql` 命令时确保路径正确
3. 检查文件权限

### Q5: 密码包含特殊字符

**解决**：
- 如果密码包含特殊字符，在 `.env` 文件中用引号包裹：
  ```env
  DB_PASSWORD="your@password#123"
  ```

## 宝塔面板特定配置

### 防火墙设置

如果无法连接数据库，检查宝塔面板的防火墙设置：
1. 在宝塔面板中，找到 **"安全"** 菜单
2. 确保 PostgreSQL 端口（默认 5432）已开放
3. 如果使用云服务器，还需要在云服务商控制台开放端口

### 性能优化

在 PostgreSQL 管理器中：
1. 点击 **"性能调整"** 菜单
2. 根据服务器配置调整参数
3. 点击 **"保存"**
