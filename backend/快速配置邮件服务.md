# 🚀 快速配置邮件服务

## ⚠️ 当前问题

从截图看到错误："邮件服务未配置，请联系管理员"

这是因为后端缺少 SMTP 邮件服务配置。

---

## ✅ 解决步骤（3步）

### 步骤 1：编辑 `.env` 文件

打开文件：`D:\piccco3-new\backend\.env`

找到以下行并填写您的邮箱信息：

```env
SMTP_HOST=smtp.gmail.com        # 邮箱服务商地址
SMTP_PORT=465                    # 端口（Gmail/QQ/163 用 465）
SMTP_SECURE=true                 # 是否使用 SSL（Gmail/QQ/163 用 true）
SMTP_USER=your-email@gmail.com   # 您的邮箱地址
SMTP_PASS=your-app-password      # 邮箱密码或授权码
```

### 步骤 2：获取邮箱授权码

#### 如果使用 Gmail：

1. 登录 Google 账号
2. 进入"安全性" → 开启"两步验证"
3. 进入"应用专用密码" → 生成新密码
4. 复制生成的 16 位密码（格式：`abcd efgh ijkl mnop`）
5. 将密码填入 `SMTP_PASS`

#### 如果使用 QQ 邮箱：

1. 登录 QQ 邮箱
2. 设置 → 账户 → 开启"POP3/SMTP服务"
3. 获取授权码（16位字符）
4. 将授权码填入 `SMTP_PASS`

#### 如果使用 163 邮箱：

1. 登录 163 邮箱
2. 设置 → POP3/SMTP/IMAP → 开启"SMTP服务"
3. 获取授权码
4. 将授权码填入 `SMTP_PASS`

### 步骤 3：重启后端服务器

配置完成后，重启后端服务器：

```powershell
# 方法 1：使用 PowerShell（推荐）
cd D:\piccco3-new\backend
Get-Process | Where-Object {$_.Id -eq 9048} | Stop-Process
npm start

# 方法 2：手动
# 1. 在任务管理器中结束 Node.js 进程（PID: 9048）
# 2. 打开新的终端窗口
# 3. cd D:\piccco3-new\backend
# 4. npm start
```

## 📋 配置示例

### Gmail 配置示例：

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@gmail.com
SMTP_PASS=abcd efgh ijkl mnop
```

### QQ 邮箱配置示例：

```env
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-email@qq.com
SMTP_PASS=your-16-char-auth-code
```

## ✅ 验证

重启后端后：

1. 刷新前端页面：http://localhost:5173
2. 尝试重置密码
3. 点击"发送验证码"
4. 检查是否收到邮件

如果收到邮件，说明配置成功！✅

---

## 🆘 如果还是不行

1. **检查 `.env` 文件格式**：
   - 确保没有多余的空格
   - 确保每行格式正确
   - 确保没有引号（除非密码中包含特殊字符）

2. **检查后端日志**：
   - 查看后端服务器控制台输出
   - 查找 SMTP 相关错误信息

3. **测试连接**：
   - 确认邮箱服务商的 SMTP 服务已开启
   - 确认授权码/密码正确

---

## 📝 注意事项

- ⚠️ **不要将 `.env` 文件提交到 Git**
- ⚠️ **Gmail 必须使用应用专用密码，不能用普通密码**
- ⚠️ **QQ/163 必须使用授权码，不能用登录密码**
- ✅ **配置后必须重启后端服务器才能生效**
