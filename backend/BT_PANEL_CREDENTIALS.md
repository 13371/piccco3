# 宝塔面板账号密码查看和重置

## 查看当前账号密码

### 方法1：使用宝塔命令查看

```bash
# 查看宝塔面板账号密码
bt default
```

这个命令会显示：
- 面板地址
- 用户名
- 密码

### 方法2：手动查看配置文件

```bash
# 查看用户名
cat /www/server/panel/data/admin_path.pl

# 查看密码（已加密，需要解密）
cat /www/server/panel/data/admin.pl
```

## 重置账号密码

### 方法1：重置为默认（推荐）

```bash
# 重置账号密码为默认值
bt 5
```

这会重置密码并显示新的账号密码。

### 方法2：只重置密码

```bash
# 重置密码（保持用户名不变）
bt 6
```

### 方法3：重置用户名和密码

```bash
# 重置用户名和密码
bt 14
```

## 快速查看默认账号密码

在服务器上执行：

```bash
bt default
```

这会显示类似以下的信息：

```
==================================================================
宝塔面板默认信息
==================================================================
外网面板地址: http://8.136.38.126:37040/488538e0
内网面板地址: http://172.28.209.237:37040/488538e0
username: 你的用户名
password: 你的密码
==================================================================
```

## 如果忘记密码

### 重置为新的账号密码：

```bash
# 重置账号和密码
bt 5
```

执行后会显示新的用户名和密码。

### 只重置密码（保持用户名）：

```bash
# 重置密码
bt 3
```

然后输入新密码。

## 安全建议

1. **首次登录后立即修改密码**
2. **使用强密码**（包含大小写字母、数字、特殊字符）
3. **定期更换密码**
4. **不要分享密码给他人**

## 注意事项

- 重置密码后，旧的登录会话可能会失效
- 如果设置了安全入口，访问时需要加上入口路径
- 建议使用 `bt default` 查看完整的登录信息
