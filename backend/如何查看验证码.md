## 📍 查看验证码的两种方法

### 方法 1：查看后端控制台（推荐）

1. **找到运行后端服务器的终端窗口**
   - 如果后端在后台运行，需要找到启动它的终端
   - 或者重新在前台启动后端服务器

2. **点击"发送验证码"后，查看控制台输出**

   验证码会以醒目的格式显示：
   ```
   ╔═══════════════════════════════════════════════════════════╗
   ║          📧 验证码邮件（开发模式 - 未配置 SMTP）          ║
   ╠═══════════════════════════════════════════════════════════╣
   ║  收件人: zq13371@gmail.com                                ║
   ║  验证码: 123456                                           ║
   ║  有效期: 10 分钟                                          ║
   ╚═══════════════════════════════════════════════════════════╝
   ```

### 方法 2：查看浏览器控制台（开发模式）

1. **打开浏览器开发者工具**（F12）
2. **切换到"网络"（Network）标签**
3. **点击"发送验证码"**
4. **找到 `send-code` 请求**
5. **查看响应（Response）**

   响应中会包含 `devCode` 字段：
   ```json
   {
     "message": "验证码已发送到您的邮箱，请查收",
     "devCode": "123456",
     "devMessage": "开发模式：验证码已输出到后端控制台，也可在此查看"
   }
   ```

## 🚀 重新启动后端服务器（查看控制台输出）

如果看不到后端控制台输出，可以重新启动后端服务器：

### 方法 1：停止后台进程，在前台启动

```powershell
# 1. 停止当前后端服务器
Get-Process | Where-Object {$_.ProcessName -eq "node" -and (Get-NetTCPConnection -OwningProcess $_.Id -ErrorAction SilentlyContinue | Where-Object {$_.LocalPort -eq 4000})} | Stop-Process

# 2. 在前台启动（可以看到所有输出）
cd D:\piccco3-new\backend
npm start
```

### 方法 2：查看进程输出

如果后端在后台运行，可以：

1. **打开任务管理器**（Ctrl+Shift+Esc）
2. **找到 Node.js 进程**（PID: 4792）
3. **右键 → 转到详细信息**
4. **查看进程的详细信息**

## 🆘 如果还是看不到

1. **确认后端服务器正在运行**：
   ```powershell
   netstat -ano | Select-String ":4000"
   ```

2. **检查后端日志**：
   - 查看是否有错误信息
   - 确认 `NODE_ENV=development` 在 `.env` 文件中

3. **手动测试 API**：
   ```powershell
   # 在 PowerShell 中执行
   $body = @{ email = "zq13371@gmail.com" } | ConvertTo-Json
   Invoke-RestMethod -Uri "http://localhost:4000/api/auth/send-code" -Method POST -Body $body -ContentType "application/json"
   ```
