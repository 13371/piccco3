步骤1: 创建远程仓库
------------------------
选择以下平台之一：

1. GitHub (https://github.com)
   - 点击右上角 "+" → "New repository"
   - 仓库名: piccco
   - 不要勾选 "Initialize with README"
   - 点击 "Create repository"

2. GitLab (https://gitlab.com)
   - 点击 "New project" → "Create blank project"
   - 填写信息并创建

3. Gitee (https://gitee.com) - 国内推荐
   - 点击 "+" → "新建仓库"
   - 填写信息并创建

步骤2: 添加远程仓库
------------------------
创建仓库后，复制仓库地址（类似：https://github.com/用户名/piccco.git）

然后在项目目录运行：
git remote add origin https://github.com/你的用户名/piccco.git

步骤3: 推送代码
------------------------
git branch -M main
git push -u origin main

【认证方式】
如果提示需要登录：
- GitHub: 使用 Personal Access Token（不是密码）
- GitLab: 使用 Personal Access Token
- Gitee: 使用私人令牌

【后续更新】
每次修改代码后：
git add .
git commit -m "更新描述"
git push
